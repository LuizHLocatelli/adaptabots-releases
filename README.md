# Adapta Bots — Releases

Este repositório guarda apenas os **instaladores** e o **feed de atualização** (`latest.yml`) publicados pelo fluxo de release do Adapta Bots. O uso é por download direto: não há código-fonte aqui.

- **Código-fonte**: no repositório privado `LuizHLocatelli/adaptabots` (acesso da equipe).
- **Baixar o app**: aba *Releases* → `AdaptaBots-<versão>-setup.exe` (instalador Windows x64, instalação em um clique) ou `AdaptaBots-<versão>-x64.zip` (versão portátil).
- **Auto-update**: os apps instalados leem o `latest.yml` daqui sozinhos; nada a fazer para receber atualizações.
- **Instalador não assinado**: o SmartScreen do Windows mostra "unknown publisher" na primeira execução (More info → Run anyway).
